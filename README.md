# LangGraph_Chatbot_using_streamlit    # LangGraph AI Chatbot

A lightweight GenAI chatbot built using LangGraph, LangChain, Ollama, and Streamlit.

This project demonstrates stateful AI conversations using graph-based orchestration, local LLM inference, memory persistence, and conversational workflow management.

## Tech Stack

* LangGraph
* LangChain
* Ollama
* Streamlit
* Llama 3.1
* Python

## Features

* Stateful conversational AI
* Graph-based agent workflow
* Persistent chat memory
* Local LLM execution
* Real-time Streamlit interface
* Scalable GenAI architecture

## Run Locally

```bash
pip install -r requirements.txt

ollama pull llama3.1

streamlit run app.py
```

## Architecture

```text
START → Chat Node → END
```

Built for learning modern GenAI engineering, agentic workflows, memory-driven AI systems, and local LLM application development.

Because apparently humanity decided normal software was not complicated enough and invented AI orchestration frameworks.
